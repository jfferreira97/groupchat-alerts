# Security

GROUPCHAT (@GROUPCHAT_ALERTS_BOT) never asks for a private key, a seed phrase or a wallet
connection. You sign in to the web page with Telegram, and you pay by sending SOL to an
address the bot gives you.

If anyone claiming to be GROUPCHAT asks you for a private key or seed phrase, it is not us.

To report an account or bot that impersonates GROUPCHAT, message
https://t.me/GROUPCHAT_ALERTS_BOT.
